# Esthien Labs Homebrew Tap

This is the official Homebrew tap for Esthien Labs products.

## Installation

```bash
brew tap esthien/argus
brew install argus-sdk
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| `argus-sdk` | Argus SDK - Safety-supervised inference for physical systems |

## Usage

After installation:

```bash
argus --version
argus runtime-info
argus regression-eval --sample --out ./output
```
